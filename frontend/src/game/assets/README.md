# Game Assets

This folder contains all the assets used by the game projects.

## Structure

### `/single_player_game/`
Contains assets for the single player table tennis game:
- `textures/` - Surface textures (floor, etc.)
- `environments/` - 360° background environments
- `README.md` - Detailed documentation

### `/backup/`
Contains backed up assets from the original Babylon.js Editor template

## Development Notes

- Assets are organized by game mode/feature
- All assets should be optimized for web delivery
- Runtime assets are served from `/public/` folder
- Development assets remain here for organization and version control
